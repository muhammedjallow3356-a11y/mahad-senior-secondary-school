# Mahad Senior Secondary School

A professional, mobile-friendly and installable school website for Mahad Senior Secondary School.

## Included

- Responsive website for desktop, tablet and mobile
- Installable Progressive Web App (PWA) with offline app shell
- Accessible mobile navigation and semantic sections
- School values, academics, activities, news, contact form and family portal actions
- Student and parent portal call-to-action modal

## Open it on your phone

1. Publish the repository with GitHub Pages, or open it from a secure web host. PWAs require HTTPS (localhost also works for testing).
2. On Android Chrome: open the site, tap the three-dot menu, then **Install app** or **Add to Home screen**.
3. On iPhone Safari: open the site, tap **Share**, then **Add to Home Screen**.
4. The site will appear on the phone like an app and the essential files will remain available offline.

For local desktop testing:

```bash
python3 -m http.server 8000
```

Replace the Unsplash image URLs with school-owned photography before production. Connect the contact form and portal buttons to a backend/authentication service when those systems are available.
